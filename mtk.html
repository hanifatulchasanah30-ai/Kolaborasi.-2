x = harga 1 lampu
y= harga 1 hiasan dinding

- model persamaan 1 (paket 1) terdapat
= "x + y = 110.000"
persamaan 2 (paket 2) terdapat
="2x + y = 160.000"

- eliminasi
2x + y = 160.000
x + y = 110.000
---------------- -
x = 50.000

- subtitusi
x + y = 110.000

50.000 + y = 110.000
y = 110.000 - 50.000
y = 60.000

- kesimpulan jadi harga 1 buah lampu tidur adalah 50.000 rupiah dan harga 1 hiasan dinding adalah 60.000 rupiah

X + 2Y =115.000 | × 1
--------------------
= 4X + 2Y =250.000
= X + 2Y = 115.00
------------------- -
3X = 135.000
X = 135.000 dibagi 3
X = 45.000

L3 : Subtitusi
X = 45.000
2X + Y = 125.000
2 (45.00 ) + Y = 125.000
90.000 + Y = 125.000
